
# Library Book Availability Finder

## About the Project
Library Book Availability Finder is a console-based application developed
using C. It helps users search for books, check availability, sort book
records, and manage borrowing and returning operations.

## Features
- Display all books
- Search books by title or author
- Search books by Book ID
- Sort books alphabetically
- Add new books
- Borrow and return books
- Check book availability

## Data Structures and Algorithms
- Array of Structures
- Linear Search
- Binary Search
- Bubble Sort

## Technologies Used
- Programming Language: C
- Interface: Console
- Compiler: GCC

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Compile the program:

   gcc main.c -o library

4. Run the program:

   ./library

On Windows, run:

   library.exe

## Limitations
- Book records are stored in memory.
- Added books and borrowing changes are lost when the program exits.
- The project uses sample data for demonstration.
